<!-- @gov:SEC-DISCLOSURE -->
## 2. Reporting a Vulnerability

We take the security of the Inventory Stock Tracker API seriously. If you discover a security vulnerability or potential threat vector, please report it through private coordinated vulnerability disclosure (CVD).

**Do NOT report security vulnerabilities via public GitHub issues, discussions, or social channels.**

### Reporting Procedure
Please send an email to the security team:
- **Email**: `security@inventory-tracker.internal`
- **PGP Key**: Fingerprint `9F3A 4B2C 8E1D 7F60 5A3B 2C1E 0D9F 8A7B 6C5D 4E3F`

Please include the following details:
1. Product version and commit hash affected.
2. Step-by-step reproduction instructions or a minimal proof-of-concept.
3. Potential impact and attack surface assessment.

---

<!-- @gov:SEC-SLA -->
## 3. Vulnerability Response Schedule (SLA)

We adhere to the following response timeline commitments:

| Milestone | Target SLA | Description |
| :--- | :--- | :--- |
| **Initial Triage** | Within 24 hours | Acknowledgment of receipt and initial assessment |
| **Reproduction** | Within 72 hours | Confirmation and isolation of the vulnerability |
| **Remediation & Patch** | Within 14 days | Verified fix authored, tested, and staged for release |
| **Public Disclosure** | Within 30 days | Coordinated advisory publication and CVE assignment |
